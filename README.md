# Logbook

Logbook is an iOS app for keeping a personal flight log. You add flights, see your routes on a globe, and get stats on where you've been.

It is an early, in-development project. It targets iOS only.

## Features

- Flight log with lookup by flight number and date
- Globe view of your routes
- Passport view of countries and airports visited
- Monthly recaps and shareable cards
- Boarding pass import by camera scan or from the photo gallery (IATA BCBP)
- Calendar import of past flights
- Flight reminders
- Home screen widget
- Sign in with Apple

## Tech stack

- Expo and React Native, written in TypeScript, with Expo Router
- TanStack Query for data fetching
- Node and Express backend
- PostgreSQL (Neon) with Drizzle ORM and Zod validation
- Sign in with Apple, verified server-side, with HMAC-signed session tokens
- iOS widget in Swift

## Repository layout

- `app/` screens (Expo Router)
- `components/`, `context/`, `hooks/`, `lib/`, `utils/` app code
- `server/` Express API, auth and database access
- `shared/` database schema shared by client and server
- `targets/` iOS widget
- `scripts/` build helpers and SQL migrations

The `ios/` folder is generated by Expo and is not committed.

## Running it locally

You need macOS, Xcode, Node 22, npm, a Postgres database (a free Neon project works) and an Apple Developer account to run on a device.

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create your environment files from the examples and fill in your own values:

   ```bash
   cp .env.example .env
   cp .env.local.example .env.local
   ```

   Use a development database, not production. Never commit `.env` or `.env.local`.

3. Create the schema in your development database:

   ```bash
   npm run db:push
   ```

4. Start the API server:

   ```bash
   PORT=5001 npm run server:dev
   ```

5. Generate the native project and start Metro:

   ```bash
   npx expo prebuild --platform ios
   npx expo start --dev-client --lan --port 8081
   ```

6. Open `ios/Logbook.xcworkspace` in Xcode, choose your device and run.

Point `EXPO_PUBLIC_API_URL` in `.env.local` at your computer's LAN address and the server port.

# ✈️ Flight Tracker Plus

A flight tracking application built with TypeScript.

## Overview

Flight Tracker Plus is a web application that allows users to track flights in real time. It provides up-to-date information on flight status, routes, and schedules.

## Features

- Real-time flight tracking
- Flight status updates
- Route visualization
- Search flights by number or route

## Tech Stack

- **Language:** TypeScript
- **Platform:** Visual Studio

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/dmarques00000-design/flighttracker.git

# Navigate to the project folder
cd flighttracker/Flight-Tracker-Plus

# Install dependencies
npm install

# Start the development server
npm start
```
